# 网络请求测试工具使用指南

## 🎯 界面设计

### 1. **顶部标题区域**
- 显示应用名称："🌐 网络请求测试工具"

### 2. **URL 选择区域** 🎯
- **Spinner 下拉选择器**：包含多个预设测试URL
- **URL 描述区域**：显示选中URL的详细信息
- **支持的测试站点**：
  - HTTP/3 测试站 (Nginx官方)
  - Cloudflare HTTP/3 演示站
  - HTTP/3 检测站点
  - TLS 协议测试站
  - Google 首页
  - GitHub API
  - 自定义测试URL

### 3. **网络库选择区域** 📚
- **RecyclerView 列表**：显示所有可用的网络库
- **单选模式**：点击选择网络库，显示选中状态
- **支持的网络库**：
  - OkHttp：高效HTTP客户端，支持HTTP/2
  - Retrofit：类型安全REST客户端
  - Cronet：支持HTTP/3和QUIC协议
  - Volley：轻量级网络库
  - HttpURLConnection：系统内置
  - Apache HttpClient：功能丰富

### 4. **操作按钮区域** 🚀
- **测试按钮**：只有同时选择URL和网络库才启用
- **清除按钮**：重置所有选择状态

## 📋 使用流程

### 步骤 1：选择测试URL
1. 点击URL下拉选择器
2. 从预设URL列表中选择一个测试站点
3. 查看下方的URL详细描述信息

### 步骤 2：选择网络库
1. 在网络库列表中点击选择所需的网络库
2. 选中的网络库会显示为"通过"状态（绿色）
3. 测试按钮会更新显示选择的网络库名称

### 步骤 3：执行测试
1. 确保已选择URL和网络库后，测试按钮会变为可用状态
2. 点击"🚀 测试 [网络库名]"按钮
3. 会弹出测试开始提示，显示测试配置信息
4. 稍后会自动弹出详细的测试结果

### 步骤 4：查看结果
测试结果包含以下信息：
- **状态码**：HTTP响应状态码
- **协议版本**：使用的HTTP协议版本
- **URL信息**：实际请求的URL
- **响应数据**：响应体内容预览
- **技术特性**：协议特性分析（QUIC、UDP等）

## 🔧 特殊功能

### Cronet HTTP/3 测试
- 强制禁用HTTP/2协议
- 启用QUIC和HTTP/3支持
- 添加QUIC服务器提示
- 详细的协议协商信息展示

### 响应体处理
- 自动清理HTML标签
- 智能截断长内容
- 字符数统计
- 格式化展示

### 错误处理
- 网络请求异常捕获
- 用户友好的错误信息
- 详细的调试日志输出

## 📊 测试结果格式

每种网络库的测试结果都采用统一的格式化展示：

```
🌐 [网络库名] 测试结果
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📊 状态码: HTTP 200
🔗 URL: https://example.com
📦 接收字节: 1024 bytes
✅ 请求成功: 是

📄 响应体预览 (1024 字符):
┌─────────────────────────────────┐
响应内容预览...
└─────────────────────────────────┘

🔧 技术特性:
• 协议版本: HTTP/3
• UDP 传输: 是
• 多路复用: QUIC 原生支持
```

## 💡 使用建议

1. **HTTP/3 测试**：选择支持HTTP/3的URL（如nginx测试站）配合Cronet使用
2. **性能对比**：使用相同URL测试不同网络库的性能差异
3. **协议测试**：观察不同URL的协议协商结果
4. **调试模式**：查看Logcat输出获取详细的技术信息

## 🚀 优势特性

✅ **无多层弹窗**：简洁的单次选择流程
✅ **视觉状态反馈**：清晰的选择状态显示
✅ **统一结果格式**：标准化的测试结果展示
✅ **智能URL管理**：预设多种测试场景URL
✅ **详细技术信息**：深入的协议和性能分析
